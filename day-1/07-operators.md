Python Operators (Short Notes)
1. Arithmetic Operators

Used for mathematical calculations.

+ Addition
- Subtraction
* Multiplication
/ Division
// Floor Division
% Modulus (Remainder)
** Exponent (Power)

Example:

print(10 + 5)   # 15
print(10 % 3)   # 1
2. Comparison Operators

Used to compare values and return True or False.

== Equal
!= Not Equal
> Greater Than
< Less Than
>= Greater Than or Equal
<= Less Than or Equal

Example:

print(10 > 5)   # True
3. Assignment Operators

Used to assign or update values.

=
+=
-=
*=
/=
//=
%=
**=

Example:

x = 10
x += 5
print(x)   # 15
4. Logical Operators

Used to combine conditions.

and
or
not

Example:

print(True and False)   # False
5. Identity Operators

Used to compare object identity.

is
is not

Example:

a = [1]
b = a
print(a is b)   # True
6. Membership Operators

Used to check if a value exists in a sequence.

in
not in

Example:

print("aws" in ["aws", "gcp"])   # True
7. Bitwise Operators

Operate on binary numbers.

& AND
| OR
^ XOR
~ NOT
<< Left Shift
>> Right Shift
Interview Points
= → Assignment
== → Value comparison
is → Object identity comparison
/ → Float division
// → Floor division
% → Returns the remainder after division
